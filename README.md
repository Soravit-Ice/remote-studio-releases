# Remote Studio releases

Public installer delivery for [Remote Studio](https://github.com/Soravit-Ice/remote-studio).

Installers are built and tested from version tags in the source repository. Complete releases include `release-manifest.json` and `SHA256SUMS`, and are immutable after publication.

The T2ETECH Store verifies the actual installer bytes before making a release available in the Store. Application access still requires an activated paid RS license. Unsigned installers require manual installation and updates.

This repository contains release files and documentation. See the source repository for development, issue reports and release setup.

No installer is published until its required build and verification gates pass.
